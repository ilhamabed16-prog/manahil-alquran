# مناهل القرآن - دربك لن يضيق

مشروع Flutter ابتدائي قابل للتشغيل، بواجهة عربية RTL وأقسام التطبيق الأساسية:
القرآن، التحفيظ، التجويد، الأذكار، السبحة، الصلاة والقبلة، القصص، المكتبة، التحديات، الأسئلة، والإعدادات.

## التشغيل
flutter pub get
flutter run

هذه نسخة Prototype/MVP. المحتوى القرآني الكامل، ورش/حفص، التلاوات، التفاسير، أسباب النزول، مواقيت الصلاة، القبلة، الإشعارات الخلفية والتعرف الصوتي تحتاج بيانات ومصادر إنتاجية موثقة وربط Backend.
